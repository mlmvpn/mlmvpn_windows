# استفاده از MLMVPN برای ویندوز

[English](USAGE.md)

برنامه مثل یک میزکار باز می‌شود: تصویر زمینه، یک داک پایین، و برای هر امکان یک پنجره. هر چیزی که
پایین می‌آید، پنجره‌ای است که از داک، از شبکهٔ آیکون‌ها، یا با **Ctrl + K** باز می‌شود.

---

## از اینجا شروع کنید

اگر تا حالا استفاده نکرده‌اید و فقط می‌خواهید آنلاین شوید:

۱. **«اتصال سریع»** را باز کنید.
۲. دکمه را بزنید. از یک استخر عمومی انتخاب می‌کند، آنچه پیدا کرده را **می‌سنجد**، و به همانی وصل
   می‌شود که از خط شما واقعاً کار می‌کند.
۳. اگر چیزی برنگشت، **«سایفون»** یا **«گیت‌وی MLM»** را امتحان کنید. هیچ‌کدام چیزی از خودتان لازم
   ندارند.

بقیهٔ این سند برای وقتی است که بخواهید از این بهتر عمل کنید.

## موتورها

### موتورهای یک‌دکمه‌ای — هیچ چیز از خودتان لازم نیست

| پنجره | چیست | کِی انتخاب درستی است |
|---|---|---|
| **«سایفون»** | شبکهٔ ضدسانسور رایگان | اولین چیزی که وقتی هیچ‌چیز وصل نمی‌شود امتحان کنید. سقف هر اتصال حدود ۰.۷ / ۳.۱ مگابیت است — برای وبگردی خوب، برای دانلود بزرگ نه. |
| **«تور»** | مسیریابی پیازی | وقتی نمی‌خواهید مقصد آدرس شما را ببیند. ذاتاً کندتر. |
| **«لنترن»** | پروکسی domain-fronted | مسیر فرانتینگ متفاوتی از سایفون — گاهی یکی کار می‌کند جایی که دیگری نه. |
| **«گف»** | بروکر fronted | تنها موتور از چهار موتور رایگان که **UDP** را حمل می‌کند، که برای بازی مهم است. |
| **«گیت‌وی MLM»** | رله‌های رایگان VPN Gate / SoftEther | یک VPN واقعی، نه پروکسی. سرعت کاملاً به رلهٔ داوطلب بستگی دارد. |
| **«ماسک»** | MASQUE روی Cloudflare WARP | سریع و بی‌سروصدا. برای خط‌هایی که UDP را می‌اندازند، برگشت به TCP دارد. |
| **«وایرگارد»** | AmneziaWG، مبهم‌شده | |
| **«وارپ»** | Cloudflare WARP | |
| **«وارپ در وارپ»** | WARP زنجیره‌ای | وقتی خروجی WARP ساده بسته شده باشد. |

> یک موتور می‌تواند کشور خروجی را **IR** گزارش کند و باز هم درست باشد — خروجی WARP را کلادفلر
> انتخاب می‌کند، نه شما. این **نشتی نیست**.

### موتورهایی که از زیرساخت خودتان استفاده می‌کنند

| پنجره | چیست |
|---|---|
| **«نودهای V2Ray»** | کانفیگ‌های VLESS / VMess / Trojan / Shadowsocks خودتان. لینک بچسبانید، ساب‌اسکریپشن وارد کنید، بسنجید، وصل شوید. |
| **«زیرساخت ابری»** | حساب کلادفلر خودتان: استقرار یا «فرزندخواندگی» ورکرها، مدیریت KV و D1، خواندن مصرف، ساخت کانفیگ. خانوادهٔ پنل‌های BPB و Zeus. |
| **«railway»** | استقرار پنل VodiWalker روی حساب Railway خودتان از روی مخزن عمومی. |
| **«تونل گوگل‌اسکریپت»** | یک رلهٔ HTTP از طریق استقرار Google Apps Script خودتان. فقط حالت پروکسی — رلهٔ HTTP شکل مناسبی برای تونل کامل نیست. |
| **«گیت‌هاب تانل»** | نشست‌های ابری یک‌بارمصرف در حساب گیت‌هاب خودتان. |
| **«اوپن‌وی‌پی‌ان»** | پروفایل‌های OpenVPN، با همان امکانات پنجرهٔ گیت‌وی. |

## پیدا کردن آی‌پی تمیز

**«اسکنر آی‌پی»** همان چیزی است که باعث می‌شود یک کانفیگ کار کند، در حالی که همان کانفیگ برای بقیه
تایم‌اوت می‌خورد.

۱. یک ارائه‌دهنده (کلادفلر، Fastly، Akamai …) و پورت‌ها را انتخاب کنید.
۲. اسکن را شروع کنید. نتیجه‌ها به‌محض **اثبات شدن** ظاهر می‌شوند — آدرس فقط وقتی نگه داشته می‌شود که
   یک **تست سلامت واقعی** را رد کند، نه صرفاً دست‌دادن TCP.
۳. اگر کانفیگتان به SNI خاصی نیاز دارد، نتیجه را به آن **سنجاق** کنید.
۴. نتیجه را مستقیم به یک کانفیگ بدهید، یا در **«آرشیو آی‌پی»** نگه دارید.

تا وقتی اسکن مالک شبکه است، وصل کردن VPN یا اجرای تست تأخیر از یک نگهبان رد می‌شود که نگذارد این
دو بر سر پورت‌ها دعوا کنند. کاری لازم نیست بکنید؛ فقط یعنی اتصال در حین اسکن ممکن است کمی بیشتر
طول بکشد.

## رد شدن از یک مسدودسازی — ابزارهای ضدفیلتر

| پنجره | چه می‌کند |
|---|---|
| **«موتور ضد فیلتر SNI»** | پنج روش متفاوت، نه یک کلید. پنل می‌سنجد اپراتور شما واقعاً کدام‌شان را اجازه می‌دهد و با همان وصل می‌شود. |
| **«دامین فرانتینگ»** | درخواست را به یک میزبان می‌فرستد و میزبان دیگری را می‌خواهد. |
| **«کانفیگ ایران»** | کانفیگ‌های سرورلس که مخصوص شبکه‌های ایران ساخته می‌شوند. «کدام کانفیگ مناسب من است؟» در این پنل **می‌سنجد**، نه حدس می‌زند. |
| **«تحریم‌شکن»** | فقط سایت‌های تحریمی (OpenAI، Google AI و…) را از موتور انتخابی رد می‌کند و بقیه را مستقیم می‌گذارد. برنامه‌ها و سایت‌ها را انتخاب می‌کنید؛ بقیهٔ ترافیک شما دست‌نخورده می‌ماند. |

## بازی

**«شتاب‌دهی بازی»** یک خط لولهٔ واحد پشت یک دکمه است، نه یک مشت کلید. کاری که واقعاً می‌کند، به
ترتیب اهمیت:

۱. **bufferbloat آپلود.** با فاصله، بزرگ‌ترین اهرم سنجیده‌شده: روی یک خط واقعی، تأخیر زیر آپلود از
   ۱۲۶ به **۲۶۸۱ میلی‌ثانیه** با ۲۹٪ اتلاف رفت. محدود کردن خروجی درستش می‌کند.
۲. **انتخاب resolver DNS**، رتبه‌بندی‌شده بر اساس **پوشش واقعی و زمان دست‌دادن** روی خط شما — نه
   نامی که کسی ثابت نوشته باشد.
۳. **انتخاب نقطهٔ ورود**، که پراکندگی سنجیده‌شده بینشان حدود ۷۰ میلی‌ثانیه بود.
۴. **تنظیمات ماشین** — نه مورد، هرکدام **کشف‌شده** نه فرض‌شده. ضبط پس‌زمینهٔ Game DVR ویندوز معمولاً
   روشن است و پیوسته پردازنده و کارت گرافیک و دیسک می‌خورد.
۵. **پایش حین بازی** — پرش‌های تأخیر را موقع بازی تشخیص می‌دهد و **مقصر را نام می‌برد**. خودش چیزی
   را عوض نمی‌کند.

از موتورهای رایگان فقط **«گف»** UDP را حمل می‌کند. سایفون، لنترن و تور SOCKS UDP ASSOCIATE را رد
می‌کنند، و تور همیشه رد خواهد کرد — این معماری است، نه امکانی که جا افتاده باشد.

## تنظیماتی که دانستنشان می‌ارزد

**«تنظیمات»** ردیف‌به‌ردیف آینهٔ برنامهٔ اندروید است. آن‌هایی که بیشتر دنبالشان می‌گردند:

| کجا | چه |
|---|---|
| **شبکه** | DNS، پورت‌ها، حالت پروکسی، اشتراک شبکهٔ محلی — تنها جایی که این‌ها زندگی می‌کنند |
| **تنظیمات پیشرفته VPN** | MTU، پشتهٔ تونل (gvisor / system / خودکار)، مسیریابی |
| **تونل و برنامه‌ها** | مسیریابی per-app: کدام برنامه‌ها از تونل رد شوند |
| **صفحه نمایش** | ظاهر، اندازهٔ متن، تصویر زمینه، و **کلید شتاب‌دهندهٔ گرافیکی** |
| **سیستم** | وقتی ویندوز قفل می‌شود چه شود؛ VPN همیشه روشن |
| **درباره** | نسخه، بررسی به‌روزرسانی، **«گزارش خطا»** — گزارش‌های ذخیره‌شده برای فرستادن |

### پشتهٔ تونل

تونل کامل باید TCP ویندوز را جایی سر هم کند. **«سازگار (gvisor)»** این کار را در نرم‌افزار انجام
می‌دهد و همه‌جا کار می‌کند — پیش‌فرض است و پیش‌فرض می‌ماند. **«سریع (system)»** بسته‌ها را به خود
ویندوز می‌سپارد و سریع‌تر است. **«خودکار»** اول سریع را امتحان می‌کند و همان لحظه‌ای که بالا نیامد
برمی‌گردد.

### اشتراک شبکهٔ محلی

**«شبکه محلی»** می‌گذارد دستگاه‌های دیگر شبکه‌تان از تونل این ماشین استفاده کنند. همهٔ موتورها
نمی‌توانند؛ پنل می‌گوید کدام‌ها می‌توانند.

## آیکون کنار ساعت

روی آیکون MLMVPN کنار ساعت ویندوز راست‌کلیک کنید:

| | |
|---|---|
| **نمایش برنامه** | پنجره را برگردان |
| **کشیدن صفحه با کارت گرافیک** | روشن/خاموش کردن شتاب گرافیکی — **اگر پنجره سیاه یا سفید باز شد، راه‌حل همین است** |
| **باز کردن گزارش راه‌اندازی** | `startup.log` را باز می‌کند — این را به هر گزارش «باز نمی‌شود» پیوست کنید |
| **خروج کامل** | خروج کامل، با همهٔ تخریب‌ها |

سه مورد آخر عمداً اینجا هستند و نه فقط در تنظیمات: تنظیمات **داخل** پنجره است، و منوی تری را
ویندوز می‌کشد — پس وقتی پنجره کار نمی‌کند، این هنوز کار می‌کند.

## فایل‌های شما کجا هستند

| | |
|---|---|
| `%USERPROFILE%\.mlmvpn\` | تنظیمات، وضعیت ذخیره‌شده، لاگ‌ها |
| `%USERPROFILE%\.mlmvpn\startup.log` | دفترچهٔ راه‌اندازی — هر شروع، با زمان‌بندی |
| `%USERPROFILE%\.mlmvpn\crashlogs\` | گزارش‌های ذخیره‌شده، در تنظیمات › درباره › گزارش خطا |
| `%USERPROFILE%\.mlmvpn\tunnel-events.log` | دفترچهٔ خود تونل: هر اتصال، قطعی و سنجش سرعت |

**هیچ چیزی جایی فرستاده نمی‌شود.** تنظیمات فایل‌ها را نشانتان می‌دهد و پوشه را باز می‌کند؛ فرستادنشان
انتخاب خودتان است.
