# 🛡️ MLMVPN - Ultimate Anti-Filter & IP Scanner

یک ابزار جامع و قدرتمند برای اسکن آی‌پی‌های تمیز (CDN)، دور زدن فیلترینگ با موتور پیشرفته SNI Spoofer، و مدیریت نودهای V2Ray برای دسکتاپ و موبایل.

## ✨ ویژگی‌های کلیدی (Features)
*   **اسکنر فوق‌سریع آی‌پی:** پیدا کردن آی‌پی‌های تمیز Cloudflare, Akamai, Fastly و...
*   **موتور SNI Spoofer:** دور زدن فیلترینگ بدون نیاز به سرور واسط با تکنیک‌های پیشرفته.
*   **تست و بهینه‌سازی نودها:** بررسی پینگ (TCP Ping)، تأخیر (Delay) و سرعت نودهای V2Ray.
*   **ساخت کانفیگ موبایل:** تولید سریع لینک و QR Code با آی‌پی تمیز و SNI فیک برای استفاده مستقل در گوشی.
*   **مانیتورینگ زنده:** بررسی مصرف ترافیک و سرعت لحظه‌ای شبکه.
*   **رابط کاربری حرفه‌ای:** طراحی مینیمال و تاریک (Dark Mode) الهام گرفته از محیط‌های توسعه (IDE).

## 💡 راهنمای استفاده سریع (Quick Start)
1. برنامه را باز کرده و در پنل سمت چپ، ارائه‌دهندگان (مثل کلودفلر) و پورت‌ها را انتخاب کنید.
2. دکمه **شروع اسکن** را بزنید تا بهترین آی‌پی‌ها پیدا شوند.
3. در تب **موتور ضد فیلتر**، یک SNI انتخاب کرده و موتور را روشن کنید.
4. کانفیگ‌های خود را در تب **نودهای V2Ray** قرار دهید و با یک کلیک به اینترنت آزاد متصل شوید!
